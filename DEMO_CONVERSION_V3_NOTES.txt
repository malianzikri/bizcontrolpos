BIZCONTROL POS V1.8.8 — DEMO CONVERSION SCREEN V3
==================================================

Tujuan
------
Mengubah akhir Demo menjadi direct-purchase-first:

Demo selesai
-> Rp79.000/bulan (direct checkout)
-> Lifetime Rp699.000
-> Tanya Admin sebagai opsi bantuan

Bukan lagi:
Demo -> wajib WhatsApp -> checkout.

Perubahan UX
------------
1. Setelah DemoGuideCompleted, conversion screen muncul otomatis.
2. Paket Rp79.000/bulan menjadi CTA utama.
3. Paket Lifetime Rp699.000 tetap tersedia.
4. WhatsApp diposisikan sebagai bantuan, bukan gerbang pembelian.
5. Tombol Aktivasi yang ada di banner/top/mobile juga membuka conversion screen.

Tracking
--------
Saat conversion screen tampil:
- PricingView
- DemoConversionScreenViewed

Saat orang memilih paket:
- DemoPurchaseIntent

Untuk Monthly direct checkout:
- InitiateCheckout (standard Meta event)
- DemoCheckoutSelected

Untuk Lifetime:
- Jika lifetimeCheckoutUrl diisi -> InitiateCheckout + DemoCheckoutSelected
- Jika belum diisi -> kembali ke landing #harga dan mencatat DemoLifetimePricingFallback

Saat Tanya Admin:
- DemoSupportClick
