# BizControl Online V1.9.3 — Report Table Search

## Perubahan
- Menambahkan tombol **Cari** dan **Reset** pada tabel **Laporan Penjualan**.
- Pencarian dapat menemukan invoice, customer, nomor HP, produk, metode pembayaran, catatan, status lunas/belum lunas, tanggal, dan nilai transaksi.
- Search digabung dengan filter periode (bulan atau rentang tanggal).
- Jumlah transaksi dan total pada header tabel dihitung dari data yang sudah difilter.
- Export **Hasil Filter CSV** mengikuti filter periode + kata kunci pencarian yang sedang aktif.
- Tombol Enter pada kolom pencarian menjalankan pencarian.
- Layout search responsif untuk desktop dan mobile.

## Database
Tidak ada migration SQL baru. Update ini hanya mengubah UI/filter laporan.
