# BizControl Online V1.8.8 — Period & Annual Reports

## Perubahan
- Kasir: filter per bulan ATAU rentang tanggal awal–akhir.
- Kasir: Export CSV mengikuti periode yang sedang dipilih.
- Biaya: filter per bulan ATAU rentang tanggal awal–akhir.
- Biaya: total dan Export CSV mengikuti periode yang dipilih.
- Laporan: Laba Rugi dapat diganti per bulan.
- Laporan: Ringkasan Periode mengikuti bulan laporan.
- Laporan: Tren diubah dari 6 bulan menjadi 12 bulan Januari–Desember.
- Laporan: tahun tren dapat diganti.
- Laporan: Export Tren 12 Bulan CSV.
- Mobile: filter periode menggunakan layout 1–2 kolom agar tetap nyaman di Feed kecil/HP.
- Mobile: tabel laporan tetap menggunakan card responsive yang sudah ada.

## Database
Tidak ada migration SQL baru. V1.8.8 hanya mengubah frontend/reporting terhadap data yang sudah dimuat dengan mekanisme RLS/RPC V1.8.7.2.

## Deploy
1. Backup source production saat ini.
2. Pastikan `runtime-config.js` tetap memakai Project URL dan Publishable Key production milik Anda.
3. Replace file frontend dengan source V1.8.8.
4. Push ke GitHub / deploy Vercel.
5. Setelah Vercel Ready, hard refresh. Bila PWA masih menampilkan versi lama: Application → Service Workers → Unregister, lalu Clear site data sekali.
6. Pastikan sidebar menampilkan `ONLINE V1.8.8`.
