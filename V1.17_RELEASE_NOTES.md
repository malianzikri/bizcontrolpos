# BizControl Online V1.17 — Production Readiness

## SaaS Subscription
- `saas_plans` dan `business_subscriptions`.
- Trial otomatis bisnis baru: 14 hari + 3 hari grace.
- Existing business di-grandfather aktif saat migration.
- Expired/Suspended = safe read-only.
- Admin Sistem dapat mengelola plan/status/expiry/grace.
- Starter: maks 2 user termasuk Owner, 500 produk.
- Business: maks 5 user termasuk Owner, 3000 produk.
- Pro: unlimited pada limit tersebut.
- Cloud dibatasi 1 bisnis per Owner sampai modul Multi Outlet dibuat resmi.

## Production Safety
- Subscription write guard berada pada database trigger untuk transaksi, sale items, pembayaran, produk, biaya, pembelian, shift, refund, opname, recipe, customer, dan loyalty.
- Service-role maintenance tetap diizinkan.
- Membership insert/update ikut diblokir ketika subscription tidak aktif.

## Onboarding
- Checklist profil bisnis, produk, printer, transaksi pertama.
- Thermal printer test receipt dari browser.

## Backup & Restore Safety
- Backup JSON memakai metadata V1.17.
- File backup dapat diverifikasi tanpa menulis data.
- History export/verify disimpan.
- In-app destructive restore tidak disediakan; production restore mengikuti database backup procedure.

## Monitoring
- `app_events` + client telemetry sanitization.
- Owner/Admin melihat health summary.
- Error network/runtime penting dicatat dengan throttle.

## Offline Strategy
- Service Worker cache app shell V1.17.
- Offline = read-only, transaksi tidak di-queue.
- Pendekatan ini mencegah conflict/duplicate invoice dan stock drift.
