# BizControl Online V1.9.0

## Perubahan utama
- Menu Kasir sekarang fokus 100% pada transaksi POS; tabel histori penjualan dipindahkan ke Laporan > Laporan Penjualan.
- Menu Pembelian baru dengan tab Purchase Order, Penerimaan Barang, dan Supplier.
- PO tidak langsung menambah stok. Stok bertambah hanya saat barang diterima.
- Mendukung penerimaan penuh/sebagian dan status Draft/Dipesan/Diterima Sebagian/Selesai/Dibatalkan.
- Hutang supplier dihitung dari Total PO - Dibayar, dengan pencatatan pembayaran supplier sederhana.
- Kategori produk baru: Bahan Baku.
- Hak akses: Owner/Admin/Finance mengelola pembelian; Gudang dapat melihat PO dan menerima barang.
- Mobile navigation sudah memasukkan menu Pembelian.

## Supabase Cloud
Sebelum memakai fitur Pembelian pada mode Cloud, jalankan `migration-v1.9-purchasing.sql` di Supabase SQL Editor. Migration menambahkan tabel suppliers, purchase_orders, purchase_order_items, RLS, serta RPC atomik create_purchase_order dan receive_purchase_order.

## Catatan akuntansi
PO adalah dokumen pemesanan, bukan biaya operasional. Penerimaan menambah stok. Nilai belum dibayar tampil sebagai hutang supplier.
