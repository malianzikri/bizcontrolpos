# BizControl V1.8.7.1 — Runtime / Boot Fix

Perbaikan:
- `runtime-config.js` tidak lagi disimpan oleh Service Worker.
- Jika Cloud bootstrap gagal, aplikasi kembali ke layar login dengan pesan error lengkap,
  bukan meninggalkan dashboard kosong.
- Console helper:
  `BizControlDeploymentStatus()`

## Cek runtime-config
Buka:
- Local: `http://localhost:5500/runtime-config.js`
- Vercel: `https://DOMAIN-ANDA.vercel.app/runtime-config.js`

Harus berisi `supabaseUrl` dan `publishableKey`.

## Urutan migration yang diperlukan
1. Semua migration sampai V1.8.4.1 / V1.8.5
2. `migration-v1.8.6-multi-item-cashier.sql`
3. `migration-v1.8.7-invite-only-access.sql`

kemudian jalankan ulang V1.8.7. Keduanya dirancang dapat dijalankan ulang pada staging.
