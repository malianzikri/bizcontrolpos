# BizControl Online V1.9.1

## POS Invoice Confirmation

- Setelah checkout POS berhasil, tampil modal **Transaksi Berhasil**.
- Modal menampilkan nomor invoice, total, metode pembayaran, dan kembalian/sisa tagihan.
- Tombol **Cetak Invoice** mencetak invoice transaksi yang baru dibuat.
- Tombol **Dokumen Lain** membuka Invoice/Kwitansi/Surat Jalan.
- Tombol **Tidak Sekarang** menutup popup dan kembali ke kasir kosong untuk transaksi berikutnya.
- Invoice yang dilewati tetap bisa dicetak ulang dari **Laporan -> Laporan Penjualan**.
- ID transaksi diambil langsung dari hasil create transaction / request ID agar aman pada transaksi paralel.
