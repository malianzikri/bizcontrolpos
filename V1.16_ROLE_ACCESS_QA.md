# BizControl Online V1.16 — Role Access QA

Pengecekan meliputi:
- permission setiap role;
- menu desktop dan struktur menu mobile per role;
- Finance tidak mendapat menu POS;
- Gudang menggunakan menu Pengiriman, bukan Kasir;
- tab Stock Opname / Recipe hanya Owner, Admin, Gudang;
- Staff dashboard non-finansial;
- Gudang PO tidak merender angka finansial;
- PO Gudang Cloud memakai masked RPC;
- refund adjustment cost tidak dimuat Kasir/Gudang;
- customer point counters tidak dapat diupdate langsung oleh Kasir;

- Warehouse product master guard mencakup barcode/variant/inventory mode/HPP/harga;
- SECURITY DEFINER V1.16 menggunakan fixed search_path dan direct EXECUTE ditutup sebelum grant RPC yang diperlukan;

- semua runtime asset utama tersedia;

## Catatan visual/browser

Environment QA saat packaging memblokir navigasi browser otomatis (`ERR_BLOCKED_BY_ADMINISTRATOR`), termasuk localhost/file URL. Karena itu **role-hardening final** diverifikasi melalui static permission/data-leak audit, bukan klaim screenshot browser baru.

Core flow V1.16 yang dibuat sebelumnya tetap mencakup shift, barcode/member, promo/tax/service, checkout, refund, stock opname, recipe/BOM, dan tutup shift. Setelah deployment staging, lakukan smoke test UI per role menggunakan matrix di `ROLE_MATRIX.md` sebelum production.
